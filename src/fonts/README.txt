Neue Frutiger Georgian is proprietary and was not used.
This project self-hosts FiraGO (SIL Open Font License 1.1) — a free humanist
sans with Georgian (Mkhedruli) + Latin. Source: github.com/bBoxType/FiraGO

Georgian CAPITALS (Mtavruli) are produced by uppercasing text in JS and render
via the Noto Sans Georgian fallback (FiraGO has no Mtavruli glyphs).
