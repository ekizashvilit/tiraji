# Tiraji (ტირაჟი)

A marketplace for buying and selling second-hand, out-of-print (უტირაჟო), and old books in Georgia.

## Why

Today, buying and selling used books in Georgia happens in scattered Facebook groups where
specific books are hard to find and sellers' posts get buried. Tiraji makes book listings
searchable and persistent, and notifies buyers when a book they want gets listed.

## Status

Early planning / greenfield. Stack (planned): React + Vite + TypeScript, Tailwind + shadcn/ui,
Supabase (Postgres, Auth, Storage, Realtime), i18next (Georgian + English).
